# AMW DDS B1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden FastDDS for production multi-host use and add a built-in CycloneDDS AMW provider sharing the same RawMessage + `/autolink/topology` protocol.

**Architecture:** Two independent `ITransportProvider` / `IDiscoveryProvider` implementations (FastDDS, Cyclone). HYBRID routes `diff_host→RTPS` through the selected network provider. No shared DdsBackend abstraction. OpenDDS/Connext remain stub + external plugin.

**Tech Stack:** C++17, CMake, eProsima Fast DDS 3.x, Eclipse Cyclone DDS (`ddsc`), GTest, protobuf `ChangeMsg` / `QosProfile`.

**Spec:** `docs/superpowers/specs/2026-08-01-amw-dds-b1-design.md`

### Task 1: Hybrid — forbid SHM fallback for cross-host RTPS

**Files:**
- Modify: `autolink/autolink/transport/transmitter/hybrid_transmitter.hpp` (`InitTransmitters`)
- Modify: `autolink/autolink/transport/receiver/hybrid_receiver.hpp` (`InitReceivers` RTPS branch)

- [x] **Step 1:** In both Hybrid RTPS branches, when `CreateTransmitter/Receiver` returns null:
  - If `mapping_table_[DIFF_HOST] == OptionalMode::RTPS` **and** this `mode` is the DIFF_HOST mapping target: log `AERROR`, **do not** insert SHM substitute (leave absent / skip insert).
  - Else (same_proc/diff_proc configured as RTPS): keep SHM fallback + `AWARN`.

Concrete pattern for transmitter:

```cpp
case OptionalMode::RTPS: {
    auto tx = amw::Amw::Instance()->CreateTransmitter<M>(
        this->attr_, OptionalMode::RTPS);
    if (tx) {
        transmitters_[mode] = tx;
    } else if (mode_->diff_host() == OptionalMode::RTPS &&
               mode == OptionalMode::RTPS &&
               mode_->same_proc() != OptionalMode::RTPS &&
               mode_->diff_proc() != OptionalMode::RTPS) {
        // Only DIFF_HOST uses RTPS → never SHM fallback.
        AERROR << "HybridTransmitter: RTPS unavailable for cross-host; "
                  "not falling back to SHM.";
    } else if (mode_->diff_host() == OptionalMode::RTPS &&
               mode == OptionalMode::RTPS) {
        // RTPS shared by multiple relations including DIFF_HOST.
        AERROR << "HybridTransmitter: RTPS unavailable (includes cross-host); "
                  "not falling back to SHM.";
    } else {
        AWARN << "HybridTransmitter: RTPS unavailable, falling back to SHM "
                 "(same-host relations only).";
        transmitters_[mode] =
            std::make_shared<ShmTransmitter<M>>(this->attr_);
    }
    break;
}
```

Simpler rule (preferred): **never SHM-fallback for RTPS mode if `diff_host()==RTPS`**. Always SHM-fallback only when `diff_host()!=RTPS`.

```cpp
} else if (mode_->diff_host() == OptionalMode::RTPS) {
    AERROR << "HybridTransmitter: RTPS unavailable for DIFF_HOST; "
              "not falling back to SHM.";
} else {
    AWARN << "... falling back to SHM ...";
    transmitters_[mode] = std::make_shared<ShmTransmitter<M>>(this->attr_);
}
```

Mirror in `hybrid_receiver.hpp`.
